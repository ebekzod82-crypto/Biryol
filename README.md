# Biryol V3 — ishlaydigan MVP

## Ishga tushirish
1. Node.js 18+ o‘rnating.
2. Terminalda loyiha papkasiga kiring.
3. `npm start` ni ishga tushiring.
4. Brauzerda `http://localhost:3000` ni oching.

## API
- GET /api/health
- GET /api/businesses?q=
- GET /api/items?q=
- POST /api/register
- POST /api/login
- POST /api/businesses
- POST /api/items

Ma’lumotlar `data.json` faylida saqlanadi. Bu MVP uchun soddalashtirilgan lokal saqlash; keyingi bosqichda PostgreSQL/production DB va SMS auth ulanadi.
